# Feature 123: Spec-Specific State Injections (Evoker Stasis & Druid Shapeshifts)\n\n## Objective\nImplement tracking for class-specific combat states that significantly alter the interpretation of a player's actions, specifically Evoker `Stasis` spell buffering/releases and Druid `Bear Form`/`Cat Form` shapeshifting. We will implement three presentation formats (Inline, Summary, and Verbose) and expose them via a CLI flag for A/B/C testing the AI's reasoning capabilities.\n\n## Architecture\n\n### 1. Data Extraction (`packages/shared/src/utils/combatStates.ts`)\nCreate a new utility module to encapsulate state-tracking logic, preventing bloat in the main timeline builder.\n\n*   **`extractStasisEvents(unit, combat)`**:\n    *   Listens for `SPELL_AURA_APPLIED` of Stasis (370537).\n    *   While active, buffers the next 3 valid healing/utility `SPELL_CAST_SUCCESS` events.\n    *   On `SPELL_AURA_REMOVED` of Stasis (the "release"), returns an event object containing the timestamp and the array of stored spells.\n*   **`extractShapeshiftIntervals(unit, combat)`**:\n    *   Tracks `SPELL_AURA_APPLIED` and `SPELL_AURA_REMOVED` for Bear Form and Cat Form (and their variants like Dire Bear Form).\n    *   Returns an array of `IFormInterval { form: 'Bear' | 'Cat', startSeconds: number, endSeconds: number }`.\n\n### 2. Timeline Integration (`packages/shared/src/components/CombatReport/CombatAIAnalysis/matchTimeline.ts`)\nExtend `BuildMatchTimelineParams` to accept the extracted state data:\n*   `stasisEvents: IStasisEvent[]`\n*   `shapeshiftIntervals: IFormInterval[]`\n*   `stateFormat: 'inline' | 'summary' | 'verbose'`\n\n### 3. A/B/C Testing Formats\n\nThe timeline builder will mutate its output based on the `stateFormat` flag:\n\n**Format A: `inline`**\n*   **Stasis**: Appends `[STASIS STORED]` to the standard `[OWNER CAST]` line when the aura is active.\n*   **Forms**: Injects the form into the 3-second `[STATE]` tick (e.g., `[STATE] friends 1:84%:bear / 2:100`).\n\n**Format B: `summary`** (User Preference)\n*   **Stasis**: Suppresses the standard `[OWNER CAST]` line for stored spells. Instead, emits a single high-signal line at the release timestamp: `[YOU] [STASIS RELEASE] → Dream Breath, Reversion, Spiritbloom`.\n*   **Forms**: Calculates the total time spent in Bear Form during critical damage windows and adds a `## NOTABLE STATES` summary block above the timeline.\n\n**Format C: `verbose`**\n*   **Forms**: Emits a discrete chronological timeline line for every shift: `0:15 [YOU] [SHIFT] Bear Form`.\n\n### 4. CLI Runner (`packages/tools/src/printMatchPrompts.ts`)\nAdd a new argument `--state-format=<inline|summary|verbose>` defaulting to `summary`. Pass this format down into the `buildMatchPromptNew` and timeline builders.\n\n## Testing Strategy\n1.  Add unit tests in `packages/shared/src/utils/__tests__/combatStates.test.ts` verifying the Stasis buffering logic and Shapeshift interval overlap handling.\n2.  Use the CLI to generate prompts using `--state-format=summary` and `--state-format=inline` on a known Evoker/Druid log, confirming the output matches the design.\n
