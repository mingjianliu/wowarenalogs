# Healer Playstyle Analysis: Technical Report

## 1. Overview
This project involved a large-scale data collection and analysis pipeline to categorize high-rated WoW Arena healer playstyles. We successfully collected **1,282 matches** (>2300 rating, dynamic floor) and synthesized them into **7 spec-specific playstyle databases**.

## 2. Data Collection Pipeline
The collection was orchestrated via a new custom script: `packages/tools/src/buildHealerPlaystyleCorpus.ts`.

### Dynamic Threshold Logic
To ensure full coverage for less popular specs while maintaining high quality, the script uses a dynamic rating floor:
- **Initial Rating:** 2300 (Target for all specs).
- **3v3 Floor:** Gradually lowers to **2100** if the 100-match quota isn't met.
- **2v2 Floor:** Gradually lowers to **2000** if the 100-match quota isn't met.
- **Solo Shuffle Floor:** Maintains **2300** due to high volume.

### Processing Logic (Per Player)
For every healer found in a match, the following data is extracted:
1. **Talent Cluster Matching:** Uses a Python Jaccard distance bridge to match players against top-tier competitive talent nodes.
2. **Opener Signature:** The first 30 seconds of cast events.
3. **Core Sequences:** The top three 3-spell chains used most frequently throughout the match.
4. **Crisis Responses:** Automated detection of cast patterns when a teammate's HP falls below 40%.
5. **Cooldown Modifiers:** Static analysis of talent IDs to identify significant CD reductions or extra charges.

## 3. Storage Architecture

### Raw Match Corpus (Evidence)
The raw extraction payloads are persisted locally to allow for re-categorization without re-downloading logs.
- **Location:** `packages/tools/local-batch/playstyle-data/`
- **Structure:**
  ```
  playstyle-data/
  ├── discipline-priest/
  │   ├── 2v2-<matchId>.json
  │   └── 3v3-<matchId>.json
  ├── restoration-shaman/
  │   └── ...
  └── [all-healer-specs]/
  ```
- **Total Samples:** 1,282 files (~7.4 MB).

### Processed Playstyle Database (Production Data)
The final synthesized archetypes generated by AI theorycrafter sub-agents.
- **Location:** `packages/tools/src/data/playstyles/`
- **Files:**
  - `discipline-priest.json`
  - `holy-paladin.json`
  - `holy-priest.json`
  - `mistweaver-monk.json`
  - `preservation-evoker.json`
  - `restoration-druid.json`
  - `restoration-shaman.json`

## 5. Maintenance
To refresh this data in the future (e.g., after a major patch), run:
```bash
SPEC_QUOTA=100 npm run -w @wowarenalogs/tools start:buildHealerPlaystyles
```
The script will skip existing match IDs and only fetch new data to fill the quotas.
